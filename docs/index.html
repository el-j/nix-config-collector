Opening the macOS Desktop App

macOS Gatekeeper may block the app on first launch. To open it:

  1. Unzip the downloaded file
  2. Right-click nix-config-collector.app and choose Open
  3. Click Open in the security dialog

Or remove the quarantine attribute: xattr -d com.apple.quarantine nix-config-collector.app

Or install with one command (Apple Silicon):

curl -L https://github.com/el-j/nix-config-collector/releases/latest/download/nix-config-collector-darwin-arm64 -o /usr/local/bin/nix-config-collector && chmod +x /usr/local/bin/nix-config-collector

How it works

Three commands to go from your existing macOS setup to a fully reproducible Nix configuration.

🔍
Step 1

Scan

Discovers everything installed on your Mac: Homebrew formulae & casks, Mac App Store apps, system services, dotfiles, preferences, and fonts.

nix-config-collector scan -o scan.json
🗺️
Step 2

Generate

Maps 60+ Homebrew formulae to their nixpkgs equivalents. Renders three production-ready Nix configuration files using Go templates.

nix-config-collector generate -o ~/.config/nixpkgs/
🚀
Step 3

Apply

One command to generate and immediately apply the configuration with nix-darwin. Use --dry-run to preview first.

nix-config-collector apply --dry-run

What gets generated

Three ready-to-use Nix configuration files, all from a single scan.

⚙️

darwin-configuration.nix

  • ✓ System packages from nixpkgs
  • ✓ Homebrew configuration
  • ✓ Dock & Finder preferences
  • ✓ Keyboard & trackpad settings
  • ✓ nix-daemon & flakes enabled
🏠

home.nix

  • ✓ User packages
  • ✓ Shell configuration (zsh/bash/fish)
  • ✓ Git config (name + email)
  • ✓ home-manager enabled
  • ✓ State version set
❄️

flake.nix

  • ✓ nixpkgs-unstable input
  • ✓ nix-darwin module
  • ✓ home-manager module
  • ✓ aarch64/x86_64 support
  • ✓ Hostname-based config

What gets scanned

Comprehensive system inventory across all categories.

📦

Homebrew Packages

Formulae and casks with versions. 60+ mapped to nixpkgs equivalents automatically.

brew list --formula --versions
🍎

Mac App Store

All MAS apps with their App Store numeric IDs for use in masApps config.

mas list
⚙️

System Services

LaunchAgents and LaunchDaemons with PID and enabled status.

launchctl list
📝

Dotfiles

Shell configs, git config, SSH config, starship, nvim, and custom paths.

~/.zshrc ~/.gitconfig …
🖥️

System Preferences

Dock, Finder, keyboard repeat, trackpad settings mapped to system.defaults.

defaults read
🔤

Fonts

User and system fonts (TTF, OTF, TTC) from all standard macOS font directories.

~/Library/Fonts /Library/Fonts

Architecture

Hexagonal architecture (ports & adapters) for clean separation of concerns and testability.

Project structure

cmd/
  cli/         ← Cobra CLI commands
  wails/       ← Desktop app (Wails 2)
internal/
  core/
    models/    Domain types
    ports/     Interfaces
    mapper/    60+ Brew→Nix mappings
    generator/ Template rendering
    app/       Orchestration
  adapters/
    macos/     System scanner
    fs/        File writer
    cli/       ANSI notifier
    git/       Git operations
    ai/        Claude AI adapter
pkg/
  config/      Embedded templates
frontend/      Vue3 + PrimeVue 4

Data flow

1
Scan
brew, mas, launchctl, defaults, fonts
↓ []Package, []Service, []Dotfile…
2
Map
Homebrew → nixpkgs attr names
↓ Package.NixName populated
3
Generate
Go text/template → .nix files
↓ darwin.nix + home.nix + flake.nix
4
Write
Timestamped backups, 0640 perms
